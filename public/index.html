How Caesar Cipher Works

Five simple steps behind one of history's oldest ciphers.

1

Select a shift value

Choose any number between 0 and 25 as your secret key.

2

Move each letter

Every letter travels forward by that number of positions.

3

Wrap around Z

After Z the alphabet loops back to A, keeping it in range.

4

Get ciphertext

The shifted text becomes your encrypted message.

5

Reverse to decrypt

Shifting backward by the same key restores the original.

🛡️

Is Caesar Cipher Secure?

Caesar Cipher is an educational classical encryption technique. Because there are only 26 possible shifts, it can be easily broken using brute force and should not be used to protect real sensitive information.
